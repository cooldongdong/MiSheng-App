# 把自己的遊戲放上網

寫給要發布遊戲的人。**不需要安裝任何軟體，也不需要會寫程式。**

---

## 你需要的東西

一份填好的遊戲試算表（或一個裝著 7 張 CSV 的資料夾），還有一個免費帳號——
下面兩個平台選一個就好。

---

## 第一步：匯出

1. 打開 <https://misheng.app/create>
2. 貼上你的 Google 試算表連結，或把遊戲資料夾拖進去
3. 檢查通過之後，左邊那一欄按 **「匯出可上架的遊戲」**
4. 你會拿到一個 `.zip` 檔

裡面長這樣：

```
你的遊戲名/
  index.html            ← 播放器，不用改
  assets/               ← 播放器的程式碼
  game/                 ← 你的遊戲
    rundown.csv           7 張表都在這裡，還是原本的 CSV
    mission.csv           想改就直接改，用試算表打開就可以
    …
    img/                  圖片
  圖片對照.csv          ← 哪個檔名對應原本哪條連結
  怎麼把這個遊戲放上網.txt
```

> **圖片欄位會被改寫。** 本來填 Google Drive 連結的格子，會變成檔名——因為圖片
> 已經下載進 `img/` 了。對照關係記在 `圖片對照.csv`。其他欄位（關卡、對白、答案、
> 提示）一個字都不會動。

---

## 第二步：選一個地方放

### 選項 A：Cloudflare（推薦）

**zip 直接拖進去就好，連解壓縮都不用。**

1. 註冊／登入 <https://dash.cloudflare.com>
2. 找到 **Workers & Pages** 設定頁
3. 點 **Create application**
4. 點 **Upload your static files**
5. 把遊戲包拖上去（zip 或解壓後的資料夾都可以）
6. 點 **Visit**，部署完成

網址會長得像 `某某某-1234.workers.dev`。

> Cloudflare 正在把舊的 Pages 收進 Workers，所以上面這條路建出來的是一個
> **Worker**，網址是 `workers.dev` 而不是舊文件裡寫的 `pages.dev`。同一個選單、
> 同一個位置，只是產品換了。

**要改遊戲的時候**：回到 Workers & Pages 找到那個專案，重新上傳一次新的 zip。

---

### 選項 B：GitHub Pages

⚠️ **先讀這一段再決定。**

GitHub 免費方案的 Pages **只能用在公開的 repo**。而你的 7 張 CSV 就放在裡面——
也就是說**任何人都可以在 GitHub 上直接翻你的答案、提示、分支**，搜尋引擎也收得到。

對「防止玩家不小心被雷」來說這是不及格的。要用 GitHub Pages，就要接受這件事，
或是升級到付費方案（私有 repo 也能開 Pages）。

如果你可以接受：

1. 把 zip **解壓縮**
2. 在 GitHub 開一個新的 repo（Public）
3. 在 repo 頁面按 **Add file** → **Upload files**，把解壓後**資料夾裡面的東西**
   全部拖進去（不是拖那個資料夾本身——`index.html` 要在最上層）
4. 按 **Commit changes**
5. 進 **Settings** → 左邊 **Pages** → Source 選 **Deploy from a branch**，
   分支選 `main`、資料夾選 `/ (root)`，按 **Save**
6. 等一兩分鐘，網址會是 `你的帳號.github.io/repo名字/`

---

### 選項 C：Vercel

Vercel 沒有拖拉上傳，不接 git 的話要用命令列工具（需要安裝 node）。
**這條路跟本文件的前提衝突，所以不推薦**——除非你本來就在用 Vercel。

---

## 第三步：驗收

用**手機**打開那個網址玩一次。桌機看起來對，不代表手機上對——這是給手機玩的遊戲。

至少確認三件事：

- [ ] 封面圖有出來
- [ ] 每一關的底圖、角色立繪都有出來（缺圖會是一片深灰）
- [ ] 答對一關之後關掉再打開，進度還在

---

## 之後要改遊戲

**改 `game/` 裡面的 CSV，重新上傳，就生效了。** 不用重新匯出、不用重新產生。

- Cloudflare：進專案 → Create a new deployment → 拖新的資料夾或 zip
- GitHub：在 repo 裡把檔案換掉、commit

> 玩家如果之前玩過，瀏覽器可能還記著舊的檔案。請他重新整理一次（手機上是下拉刷新）。

---

## 常見狀況

**畫面說「這個遊戲讀不起來」**

- 如果網址開頭是 `file://`——不行。瀏覽器不允許網頁那樣讀資料，一定要放上網站空間。
- 如果說「找不到 game/○○.csv」——那張表沒有被上傳到。7 張都要在。

**圖片沒出來，變成一片深灰**

圖片的檔名要跟表格裡填的**一模一樣**，含大小寫和副檔名。`Fengmian.JPG` 和
`fengmian.jpg` 是兩個不同的檔案。

**改了 CSV 但遊戲沒變**

重新整理。還是沒變的話，用無痕視窗開一次確認——那是瀏覽器的快取，不是你改錯。

**同一個網域下放了兩個遊戲，存檔會打架**

存檔是用 `config.csv` 的 `id` 當名字的。兩個遊戲的 `id` 如果一樣，進度會互相覆蓋。
**放第二個遊戲時記得把 `id` 改掉。**

---

## 一件要先知道的事：這條路藏不住答案

遊戲的資料就是幾個放在網路上的 CSV 檔，**打定主意要看的人一定看得到**。

對實境解謎來說這通常沒關係——要防的是「玩家不小心瞄到」，不是防駭客。但如果你的
遊戲有商業考量，請把這件事算進去。

（GitHub Pages 又更糟一層，因為 GitHub 會把表格整齊地列出來給人看。）
