# character：角色

一列就是一個角色。對白上的頭像與立繪從這裡來。

| 欄位 | 說明 |
|---|---|
| `name` | **必填、不可重複**。rundown 與 hint 的 `speaker` 靠它找到這個角色 |
| `avatar` | 頭像圖 |
| `straight` | 立繪圖 |

::: warning 兩個角色同名的話
只會用到第一個——第二個角色的立繪與頭像會靜靜地變成第一個的。
不會報錯，就是換了張臉。
:::

## 立繪要做多大

**尺寸不重要，比例才重要。** 立繪會被完整縮放進畫面（不裁切）、**上緣對齊畫面頂端**，
所以圖檔是 1080 還是 2000 像素寬都一樣，決定長相的只有兩件事：**畫布比例**、
以及**人物在畫布裡的位置**。這兩件是分開的旋鈕，搞混了就會一直試不出來。

### 建議：1080 × 1920（9:16）

[📐 下載版型（SVG）](/character-template.svg) —— 丟進 Figma／Illustrator 當底圖，
三條線標好了該把人物放在哪。

| 圖片的位置 | 那裡會發生什麼 |
|---|---|
| **0–10%** | 留白。**頭頂不要進來**，否則人物會貼到畫面頂端 |
| **10–55%** | **安全區**。臉與上半身放這裡——這一段在所有手機上都看得到 |
| 55–77% | 高的手機看得到，矮的手機（iPhone SE）會被對白框蓋住 |
| **77–100%** | 會被對白框與漸層蓋住。人物的腳、衣襬放這裡，**讓它自然融進漸層** |

那幾個百分比是量出來的，不是估的：對白框的高度在各種手機上都是 275–282px，
但畫面高度不同，所以它咬進圖片的位置會落在 74–79% 之間（iPhone SE 因為螢幕矮，
會咬到 55%）。**表格取的是最保守的那一個。**

### 為什麼不要用 3:4 或 4:5

那兩個比例太扁，縮放後**下方會多出一塊空白**，而空白比對白框還高——於是人物底下
露出一條主題底色。9:16 剛好讓多出來的部分全部藏進對白框底下。

### 另一種做法：讓立繪自己就是背景

也可以不做透明背景的人物，而是**把人物與場景畫成一整張不透明的圖**（demo 就是這樣，
2:3、滿版、四角都有內容）。那樣連 `backgroundImg` 都不用填。

兩條路的差別只有一個：**要不要讓同一個角色出現在不同場景**。要的話就用透明 PNG ＋
`backgroundImg`；不要的話一張圖最省事。

::: tip 人物頂天立地是怎麼來的
畫布比例太瘦長（例如 9:19.5）時，圖會被撐滿整個畫面高度，頭就貼到頂端了。
**要讓頭離頂端有距離，是在圖裡留白，不是把畫布改扁**——後者會讓底下露出空白。
:::

## 不想登記角色也可以

`speaker` 留空、改用 `title` 寫名字，畫面上照樣顯示那個名字，
只是不會有頭像與立繪。

適合只出現一次的路人。
