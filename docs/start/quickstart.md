# 五分鐘做出第一款遊戲

## 1. 複製範本試算表

從 demo 的資料開始改，比從空白開始快得多——七張表的欄位都已經在那裡了。

## 2. 改三個地方就有一款自己的遊戲

| 改哪裡 | 效果 |
|---|---|
| `config` 的 `title` | 遊戲叫什麼 |
| `rundown` 的 `text` | 玩家看到的每一句話 |
| `mission` 的 `answer` | 謎題的答案 |

其他欄位先不用管，留著 demo 的內容也不會壞。

## 3. 貼進 /create 看結果

打開 [misheng.app/create](https://misheng.app/create)，貼上你的試算表連結
（記得把共用權限開成「知道連結的人都可以檢視」）。

當場就會檢查有沒有問題，然後可以直接試玩。

::: tip 改了試算表，畫面沒變？
按「重新讀取」。謎生不會自己去輪詢你的試算表。
:::
