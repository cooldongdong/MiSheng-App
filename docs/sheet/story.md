# story：劇情圖

一列就是一張劇情圖。玩家在故事頁看得到。

| 欄位 | 說明 |
|---|---|
| `missionId` | 這是哪一關的故事 |
| `title` | 標題（選填） |
| `img` | 圖片 |

玩家可以點開放大。

::: warning 這張表的圖，進關就看得到
故事頁沒有鎖——玩家一進這一關，這張表裡屬於這一關的圖就全部列出來了。
所以這裡**不適合放會洩漏答案的東西**。

想要「解完才看得到」的，把它放在 rundown 的流程上（解完謎之後的那個位置），
然後勾 `story` 欄——這一關解完，它就會收進故事頁，排在這張表的圖後面。
見 [rundown 的 story 欄](/sheet/rundown#收進故事頁-story)。
:::
