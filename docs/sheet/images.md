# 圖片怎麼填

所有 `img`、`avatar`、`backgroundImg`、`straight` 之類的欄位，都是填**圖片的位置**。

## 方法一：貼網址

Google 雲端硬碟的分享連結可以直接貼——謎生會自己轉換成看得到的格式。

::: warning 權限要開
共用權限設成「**知道連結的人都可以檢視**」，否則只有你看得到，玩家看到的是破圖。
:::

其他圖床的直接連結也可以。

## 方法二：用本機資料夾

把圖片放在一個資料夾裡，在 `/create` 選「改用本機資料夾」。
這時候欄位改填**檔名**就好（例如 `土地公.jpg`）。

適合圖片還在調整、不想每改一次就重新上傳的階段。

## 該做多大、什麼比例

遊戲畫面是一支直立的手機（大約 415×900），所以**多數圖都是直式的**。

| 用在哪 | 比例 | 建議尺寸 | 怎麼被顯示 |
|---|---|---|---|
| `backgroundImg`（封面、關卡、單頁背景） | **直式 2:3 或 9:16** | 1080×1920 | 填滿整個畫面，**超出的部分會被裁掉** |
| `straight`（角色立繪） | **直式 2:3 或 9:16** | 1024×1536 | 完整放進畫面、**上緣對齊**，不會被裁 |
| `avatar`（角色頭像） | **正方形 1:1** | 600×600 | 裁成圓形，只顯示大約 40 點 |
| `prop` / `story` 的圖 | 任何比例 | 長邊 1500 以上 | 完整顯示，玩家可以點開放大、雙指縮放 |
| `Wheel` 的四層圖 | **正方形 1:1** | 1000×1000 | 疊在一起轉，**四層要對齊同一個圓心** |

::: warning 背景圖會被裁
背景是「填滿」不是「放進去」——手機比例跟你的圖不一樣時，**短邊會被裁掉**。
重要的東西（字、關鍵物件）不要放在邊緣。

立繪相反，它是完整放進去的，所以立繪可以放心留白。
:::

::: tip 檔案大小
一張圖控制在 **300KB 以內**。實境遊戲是在戶外用手機網路玩的，
而一款遊戲可能有幾十張圖——那是玩家在路邊等著看的東西。

1080×1920 的 JPG 壓到品質 80 大約就是這個量級。
:::

## 匯出之後

匯出的資料夾裡有一份 `圖片對照.csv`，記著哪個檔名對應原本哪一條連結、用在哪一格。
圖片有問題時從那裡找最快。
