# hint：提示

一列就是一則提示。玩家在提示頁自己解鎖。

| 欄位 | 說明 |
|---|---|
| `missionId` | 這是哪一關的提示 |
| `text` | 提示內容 |
| `speaker` | 誰說的（選填） |
| `img` | 附圖（選填） |
| `timer` | 選填。進這一關之後**第幾分鐘自動解鎖** |

同一關的提示會照表裡的順序顯示。

## timer：時間到就自己打開

| 填什麼 | 意思 |
|---|---|
| 留空 | 只能手動解鎖 |
| `0` | 進關就解鎖 |
| `3` | 進關後第 3 分鐘 |

倒數從**玩家離開關卡開場頁往前走**的那一刻算起，不是從進到開場頁算起——
停在那裡讀說明、看導航的時間不算。

::: tip 自動解鎖不會取代手動
玩家隨時可以自己解鎖。`timer` 是安全網，不是限制——
只剩二十分鐘的隊伍不該被要求「再等三分鐘才准看提示」。
:::

導覽列的提示圖示上會有一顆紅點，告訴玩家「有東西該看了」——
因為卡住的人正盯著謎題，不會想到去翻提示頁。
