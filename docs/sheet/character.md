# character：角色

一列就是一個角色。對白上的頭像與立繪從這裡來。

| 欄位 | 說明 |
|---|---|
| `name` | **必填、不可重複**。rundown 與 hint 的 `speaker` 靠它找到這個角色 |
| `avatar` | 頭像圖 |
| `straight` | 立繪圖 |

::: warning 兩個角色同名的話
只會用到第一個——第二個角色的立繪與頭像會靜靜地變成第一個的。
不會報錯，就是換了張臉。
:::

## 不想登記角色也可以

`speaker` 留空、改用 `title` 寫名字，畫面上照樣顯示那個名字，
只是不會有頭像與立繪。

適合只出現一次的路人。
