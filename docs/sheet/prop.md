# prop：道具

一列就是一個道具。玩家在道具頁看得到。

| 欄位 | 說明 |
|---|---|
| `missionId` | 這是哪一關的道具 |
| `type` | `Img`／`Wheel`／`Camera`／`Overlay` |
| `title` | 道具名稱 |
| `img` | `Img` 的圖；`Camera` 的套框圖；`Overlay` 疊在相機畫面上的透明圖 |

## Img：一張圖

最單純的一種。玩家可以點開放大、雙指縮放。

## Wheel：轉盤

四層圖疊起來，由下往上：

| 欄位 | 那一層 |
|---|---|
| `backImg` | 最底，**不會轉** |
| `rotateImg2` | 會轉 |
| `rotateImg1` | 會轉 |
| `frontImg` | 最上，**不會轉** |

四層都是選填，但**沒有 `rotateImg1` 就沒有東西可以轉**。

想做「固定的底圖 ＋ 只有一圈會轉」的話：底圖填 `backImg`，轉的那圈填 `rotateImg1`。

## Camera 與 Overlay 都會打開相機，差別是要幹嘛

| | `Camera` | `Overlay` |
|---|---|---|
| 用途 | 讓玩家**拍一張帶走** | 讓玩家**對準現場的東西** |
| `img` | 套在照片上的框 | 半透明疊上去的透明片 |
| 取景框 | 有（4:5） | 沒有，畫面越大越好對 |
| 透明度 | 不透明 | 半透明，可調 |
| 移動縮放 | 可以，但預設就貼齊框 | **核心**，要一直調 |
| 凍結畫面 | 沒有（凍住就拍不到人） | **有**，手會抖，先定住現實再慢慢對 |
| 鏡頭 | 前後可切，預設後 | 後鏡頭 |
| 拍照 | 有 | 沒有 |

## Camera：拍一張帶走

打開相機，把 `img` 疊在取景框上，玩家拍下來可以存到手機。適合做破關紀念、臉挖空的合照框。

**套圖請做 `1080 × 1350`（4:5）。**

輸出尺寸是固定的，不隨手機變——所以你只要做一份，每個人拍出來都一樣大。畫面上的取景框只是預覽（在不同手機上大小不同），**框外的東西不會被拍進去**。

一張 1080×1350 的圖進去之後會**正好貼滿取景框**，玩家不必自己對。他仍然可以拖曳、縮放、旋轉；動過之後會多出一顆「回正」的按鈕。

拍完有三條路存到手機：**分享**（手機原生的分享選單裡有「儲存影像」）、**下載**、或**長按那張照片**。哪一條能用看瀏覽器，所以三條都留著。

`img` 沒填也可以用，那就是一台普通的相機。

::: tip 圖片要能跨網站取用
合成照片時瀏覽器有跨來源限制。用**本機資料夾**或**匯出部署後的遊戲**都不會有問題；在 `/create` 裡貼 Google 雲端硬碟連結試玩時，如果出現「疊圖的來源不允許跨網站取用」，那張照片就只會有相機畫面、沒有套圖。部署之後就正常了。
:::

## Overlay：數位透明片

打開相機，把 `img` 半透明地疊在畫面上——玩家拿去對準現場的匾額、壁畫、地磚。

**它不可替代的場合是「疊在帶不走的東西上」。** 疊實體卡片的話，實體透明片更好用也更便宜。

三個為了對得準而有的設計：

- **拖曳、縮放、旋轉**（桌機是拖曳、滾輪、`Shift` ＋ 拖曳）
- **調透明度**
- **凍結畫面**：手舉著會抖，所以先把相機畫面定住，再慢慢把圖對上去。凍結期間圖照樣能動

`img` 沒填的話只會開出一片空相機。

::: warning 拿不到相機的時候
玩家常常是從 LINE、Instagram 的內建瀏覽器點進來的，那些地方可能給不了相機權限。這兩種道具都會退化成「純看圖」並說明原因——**所以不要把過關的唯一線索藏在只有相機看得到的地方。**
:::
