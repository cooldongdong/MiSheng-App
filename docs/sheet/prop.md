# prop：道具

一列就是一個道具。玩家在道具頁看得到。

| 欄位 | 說明 |
|---|---|
| `missionId` | 這是哪一關的道具 |
| `type` | `Img`／`Wheel`／`Camera` |
| `title` | 道具名稱 |
| `img` | `Img` 的圖；`Camera` 疊在相機畫面上的透明圖 |

## Img：一張圖

最單純的一種。玩家可以點開放大、雙指縮放。

## Wheel：轉盤

四層圖疊起來，由下往上：

| 欄位 | 那一層 |
|---|---|
| `backImg` | 最底，**不會轉** |
| `rotateImg2` | 會轉 |
| `rotateImg1` | 會轉 |
| `frontImg` | 最上，**不會轉** |

四層都是選填，但**沒有 `rotateImg1` 就沒有東西可以轉**。

想做「固定的底圖 ＋ 只有一圈會轉」的話：底圖填 `backImg`，轉的那圈填 `rotateImg1`。

## Camera：數位透明片

打開手機相機，把 `img` 半透明地疊在畫面上——玩家拿去對準現場的東西。

`img` 沒填的話只會開出一片空相機。
